# Security

Crit Plus is an enhanced fork of [Crit](https://github.com/tomasz-tomczyk/crit), originally created by **Tomasz Tomczyk**. See [NOTICE](NOTICE) for provenance.

## Reporting vulnerabilities

For vulnerabilities affecting upstream Crit, follow [the upstream security policy](https://github.com/tomasz-tomczyk/crit/security/policy), which lists `security@crit.md` as its contact. Identify the project and version in your report.

This fork does not currently define a separate security contact. Do not open a public issue containing details of an undisclosed vulnerability.
